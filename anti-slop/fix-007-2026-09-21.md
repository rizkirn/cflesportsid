# Tournament layout, schema, and test repair

## Changes

- Tournament cards use content-driven height and equal desktop grid rows. The champion row no longer pushes the completed season's Tournament info footer outside its card. CTA rows cannot shrink; poster cropping is isolated from content sizing. Mobile cards grow independently, preserving readable content and a consistent footer inset. Purpose: retain the existing competition-card design while making S1/S2 actions consistent (R-03, R-05).
- Removed the duplicate team color schema key that overrode six-digit hex validation.
- Veto tests parse map fixtures using the collection schema, preserve collection IDs, and transpile with ES2022 so Map iteration works. Coverage now includes active/default/inactive maps, sorting, valid wheel capacity, invalid picks, unsupported series, empty/exhausted pools, and session reset behavior. Production veto behavior was not changed.
- Build checker expects Astro's sitemap-index.xml.
